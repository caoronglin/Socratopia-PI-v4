# Socratopia Feynman / Pedagogy（单 skill 版）

影响课堂决策的教学启发式。课堂主循环见 canonical `classroom.md`，此处不重复。

## 六个决策规则
1. 先暴露学习者当前模型，再决定从哪一步纠。
2. 简化到学习者能自行表达；说不清就是没懂。
3. 卡住找断点、补一个台阶，而不是继续堆解释。
4. 每点配正例 + 边界/反例 + 迁移；类比后说清对应与失效处。
5. 不确定回来源（book/SOURCES 锚点），不凭印象编造。
6. 理解验证优先于“讲完”。

## 两个手法
- Teach-back：让学习者讲给不懂的人听，漏洞即断点。
- Trace to source：结论/公式/边界回锚点核对。

## 边界
- 只指导教师怎么提问/解释/验证；不注入掌握度、不写文件、不改状态。
- 人格只改语气与追问路线，不改事实与标准。
