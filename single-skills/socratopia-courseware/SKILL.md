# Socratopia Courseware（单 skill 版）

仅当用户明确说“生成课件 / 做教学 PPT / 设计课堂材料”时加载；不自动触发、不常驻。产出是 PREP/教学材料的延伸，不替代课堂。

## 方法论
1. 素材/目标分析（对接本课程 PREP 与 coverage）。
2. 知识四分类：概念 / 原理原则 / 信息工具 / 过程。
3. 内容框架：结论先行、上下对应、MECE、排序逻辑；模块克制，首模块轻量。
4. 教学设计：**4C**（联结-知识-练习-总结）或**五星教学**（聚焦问题-激活旧知-示证新知-应用练习-总结回顾）。
5. 教学方法说明表：为每知识点选方法（讲授/图示/类比/提问/案例/演示/角色扮演…）。
6. 整合自检：前后一致、活动与大纲对应、覆盖目标。
