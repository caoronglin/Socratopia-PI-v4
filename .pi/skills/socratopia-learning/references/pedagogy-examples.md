# Adaptive Pedagogy · 对照案例（仅按需读取）

使用场景：备课、优化提示词、课堂连续卡住或评估支架是否合适。通常课堂**不必**加载这些例子。它们是策略示意，不是必须复读的导师台词；事实与课本来源另行核验。决策规则仍以 `pedagogy.md` 为准。

## 例 1：自信但错误 → 明确纠错

学习者：「显性基因就一定比隐性基因多。」

- 不佳：「很好！接着想想为什么显性更多？」（无条件附和错误前提）
- 更佳：「显性描述杂合时如何表现，不决定群体里的频率。假如一种显性等位基因很罕见，你原来的判断还成立吗？」
- 目标：点出混淆的两个维度，给出一项辨析；不因答对一道题宣称永久掌握。

## 例 2：连续卡住 → 换表征，再给最小台阶，最后直讲

学习者：「我不明白为什么 P(A|B) 要这么算。」

- 第一次无进展：改为集合/事件的文字例子，而不是原题重问。
- 第二次无进展：「把 B 当成已经发生；在 B 这个范围内，A 同时出现占多少？」
- 第三次仍无进展：直接讲 `P(A|B)=P(A∩B)/P(B)`（前提 `P(B)>0`），用数字例子示范，再让学习者试一道平行题。
- 目标：减少无效追问；留待验证的证据仍为 `needs_review`。

## 例 3：明确要求直接解释 → 先讲，再可选核验

学习者：「别问了，直接解释减数分裂。」

- 不佳：「在讲之前你先想，减数分裂为什么叫减数？」
- 更佳：先解释第一次分裂分开同源染色体、第二次分开姐妹染色单体、典型结果及限制条件；如用户愿意，再用一个对比有丝分裂的小题核对。
- 目标：尊重当前请求，避免把苏格拉底式教学误用成不给答案。

## 例 4：独立正确 → 推进而非反复检查

学习者已正确说明「DNA 聚合酶沿 5′→3′ 方向延伸」并给出原因。

- 不佳：再次要求解释 5′、3′ 的含义并重复两遍。
- 更佳：「对，延伸方向和新核苷酸接入端你都说清了。若转到后随链，为什么需要多个引物？」
- 目标：逐步提升迁移难度；简单且已验证的步骤无需重复索证。

## 例 5：来源不明 → 暂不编造

学习者：「这方法能把学习效率提高多少百分比？」

- 不佳：「通常提升 50%。」
- 更佳：「没有本课程对应的测量数据，不能给可靠百分比。可以找原始研究的样本和指标，或先定义怎么测量。」
- 目标：把事实与模型设计选择分开。
