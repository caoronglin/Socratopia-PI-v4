# Coverage Ledger 与章节质量门

账本写在 `PROGRESS.md` 的 `## Coverage ledger`；本章定义判据。账本记录真实证据，**不是教学计划**（计划在 PREP）。

## 五态

| 状态 | 含义 |
|---|---|
| `unseen` | 未处理 |
| `introduced` | 讲过，但没验证 |
| `verified` | 有可观察理解证据，且期望元素逐个有证据 |
| `needs_review` | 混淆或失败，待重来 |
| `intentionally_skipped` | 仅用户明确跳过 |

**讲过 ≠ verified。** 一段流畅叙述不是证据；「懂了」也不是。

## 期望元素（覆盖的粒度）

一段讲得通顺的话很容易盖住整个概念，让人误以为覆盖完了。解决办法是把覆盖判到**元素**一级。

- **期望元素** = 该条目「说对才算懂」的 2–7 个独立子元素，如：定义、机制/推导、边界条件、反例、迁移。
- 元素在 PREP 的 `## Coverage 种子` 里**预先声明**（教研会 B 镜头主责），不是课堂上临时想。
- 判据是元素被**逐个**证到。只证到一部分时，条目停留在 `introduced`。
- 记录方式：写在 ledger 的最后一列，逐个标状态，如 `顺序✓ 反例✗ 复合迁移✗`。
- 全部元素 ✓ 才可升 `verified`，**且**仍需理解证据——元素齐不等于证据强。
- 课堂上现场发现的元素可以补录，但补录 ≠ 已证。
- 元素不是任务清单，不要求一节课清空；未证的元素进 `needs_review` 或留下一课。

章节备课时由 `prep.py chapter` 枚举教材真实小节，PREP 的“章节小节与教学单元”列明逐项活动及证据；补充资料不充当教材小节完成凭据。章节内可以跨会话推进，未达成要求就保留未完成状态，不为了“一章一课”跳过验证。

## 章节完成条件

整章覆盖属于**章级**完成条件，不由单个单元的容量决定。

完成须同时满足：

- required 小节无 `unseen`；
- 核心内容有完整深度与证据，期望元素无静默缺口；
- 图表、例题、注释、习题里的新知识已处理或明确记录；
- 能复述主线并说出至少两条关系；
- 至少一道综合题 + 一道迁移题；
- 没有未解释的 required 缺口。

**coverage auditor 的报告不是掌握证据**，只是定位工具。

未下课可继续 Unit/章、补漏、综合练习或复习；章末不自动结束课堂，也不降低质量门。
