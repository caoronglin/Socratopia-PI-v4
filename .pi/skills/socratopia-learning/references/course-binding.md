# 课程与参数绑定

仅在课程/课号解析、切换或参数冲突时读取；课堂流程见 `classroom.md`。

- 参数是数据；课程名为非空单一路径段，拒绝路径与 `..`；脚本参数单独引用，不拼接 shell 语句。
- 无课程参数用会话绑定，否则读 `DATA/LEARNER.md` 当前课程；两者冲突或未知时只问一次课程，不猜测、不遍历其他课程。单独的 `lesson_id` 仅在绑定课程内解析。
- 开课指定异课先切换；资料/健康参数只限定操作范围，不改指针。课程缺失不自动创建，blockers 未解不进新内容。

## 课程切换

1. 验证目标名及 DATA/TEXTBOOK 课程目录；目标无效时保持当前课程和指针不变，同课 no-op。
2. 仅保存旧课真实新增断点、证据与未完成项；失败停止。
3. 更新 `DATA/LEARNER.md` 当前课程字段，保留其他偏好；确认成功再绑定目标，字段缺失先报告。切课不结章、轮换或导出；旧课状态不搬运。
