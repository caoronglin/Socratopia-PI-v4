# Pedagogy · 教学决策启发式（pedagogy.md）

课堂主循环与覆盖质量门见 `classroom.md` 与 `SYSTEM/SPEC/CLASSROOM_CONTRACT.md`，本文件不重复。这里只收**真正影响课堂决策**的启发式（吸收 learning-feynman，去除冗长研究材料）。

## 六个决策规则

1. **先暴露学习者的当前模型**：提问让学习者先说出他现在的理解，再决定从哪一步纠。不要一上来就给正确解释。
2. **简化到能自行表达**：判断掌握的标准是学习者能用自己的话讲清，而不是复述定义。“不能简单解释”通常是还没理解。
3. **找断点，而不是继续堆解释**：卡住时定位推理链断裂的那一环，补那一个台阶；不要在完整链路上反复加长解释。
4. **例子 / 反例 / 迁移**：每个核心点配一个正例、一个边界或反例，再要一个迁移。类比之后必须说清对应关系与失效处。
5. **不确定就回来源**：拿不准的定义、公式、依据，回到 `book.md`/`SOURCES` 锚点确认，不凭印象编造。
6. **理解验证优先于“讲完”**：宁可少推一个点，也要拿到可观察证据；不要为了 coverage 数字降低标准。

## 与导师人格的关系

- 这些是决策规则，不随导师变化；导师只改变语气、类比与追问路线（见 `persona.md`/`profiles/`）。
- 物理图像/直觉优先：先建立“画面”或类比，再给形式化表达——但类比不能替代定义与证据。

## 两个常用手法

- **Teach-back（教是最好的学）**：让学习者把刚学的点讲给“一个不懂的人”听；讲不清的地方就是漏洞，回到那一步。
- **Trace to source（回来源）**：结论、公式、边界拿不准时，回到 `book.md`/`SOURCES` 锚点核对，不凭印象补充。

## 微例子

学习者说“我懂了余弦定理”。不要复读定理；问：“那把已知两边和**夹角**换成已知三边，该怎么求角？为什么？”——能回答并说明边界，才算有证据；卡住即断点，补那一个台阶。

## 边界

- 本文件不注入掌握度、不写文件、不改状态；只指导教师**怎么提问、怎么解释、怎么验证**。
- 具体学科解题、情感决策等超出“学习方法”范围的问题，按当前课程与工具正常处理，不强行套用本框架。
