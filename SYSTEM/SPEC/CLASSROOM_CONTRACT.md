# Classroom Contract

## 三个尺度

- Session：用户控制开始/结束。
- Teaching Unit：1–3 个核心点的可消化推进块。
- Chapter：coverage quality gate。

因此，“章必须完整覆盖”不等于“一次 Unit 必须讲完整章”。

## 掌握证据

可靠度从弱到强大致为：自述 < 提示后复述 < 独立解释/基础题 < 辨析/反例 < 迁移/综合应用。

系统不把任何单次证据永久固化为“掌握”；后续检索失败可以将状态降为 needs_review。

## Coverage 状态

`unseen → introduced → verified`

出现错误证据：`introduced/verified → needs_review`

用户明确不学：`→ intentionally_skipped`

`verified` 必须有 evidence reference。

## 课堂结束

只有用户明确结束才关闭 Session。上下文不足时保存 checkpoint 并建议续开，但不得替用户宣布下课。
