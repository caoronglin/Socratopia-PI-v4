# Agent Loop · 单次请求执行契约

本文件只定义 **Socratopia 的决策与停止规则**，不修改 Pi/Cherry 的底层事件循环。仅需精确判定边界时按需读取；常驻原则见 `AGENTS.md`。

## 一次请求的状态机

`ROUTE → INSPECT → ACT → VERIFY → (DONE | YIELD | BLOCKED | NEXT)`

| 阶段 | 进入条件 | 准许动作 | 离开条件 |
|---|---|---|---|
| ROUTE | 收到用户请求 | 分辨直答/教学/阅读/工程；有课程时绑定唯一课程 | 意图和目标明确；纯闲聊/知识问答可直接 DONE |
| INSPECT | 必须确认现状、来源、工具或授权 | 首选最小范围只读；加载一个匹配 Skill 和必要 reference | 拿到足够证据或确认无法取得 |
| ACT | 现有证据足够，用户明确要求操作 | 仅执行当前目标所需最小动作；有副作用按宿主审批 | 工具返回结果或动作被拒绝 |
| VERIFY | 已发生实际动作 | 使用实际证据验证重要结果；工程改动跑相关测试，学习核对来源/状态 | 可判定完成、阻断或下一最小动作 |
| DONE | 用户目标达成且已验证（或纯回答已给出） | 简短汇报结果、证据和未验证范围 | **结束本次 Agent 响应** |
| YIELD | 等学生作答、等用户补齐关键材料/选择或需要本次授权 | 只问一个影响下一步的问题，说明当前已知事实 | **结束本次响应，等待下一条用户输入** |
| BLOCKED | 缺工具、拒绝授权、内容不可获取、重复失败、课程状态不安全 | 说明阻断点和一个安全替代选项 | **结束本次响应，不暗中重试** |
| NEXT | 仍存在用户已授权且可验证的必要子步骤 | 继续到 INSPECT 或 ACT，保持已知证据 | 不重复已完成的步骤 |

## 继续与停止规则

1. **默认一次回答就够**：定义、解释、翻译、简短事实问答不因“Agent”二字强行进入多轮工具循环。无须依赖工具的任务不调用工具。
2. **证据驱动下一轮**：继续须说明“还缺什么才能完成用户目标”；上一轮已取得的内容不重读。无新证据/状态改变时，不重复相同工具调用。
3. **故障处理**：错误后最多进行一次针对**不同原因**的修正与重试。权限拒绝、用户取消、认证墙、工具缺失或不可逆风险直接 BLOCKED；不换渠道绕过。复杂问题可在获得新证据后继续，不以死板调用次数限制正常完成。
4. **真正的停机条件**：达到目标 → DONE；需要用户回答/选择/授权 → YIELD；当前路径不可行 → BLOCKED。禁止“为了完整”自行拓展课题、无限检索或继续发消息。
5. **并行性**：独立、只读任务可并行；同一课程状态、同一文件的写入必须顺序执行并验证，避免竞态和覆盖。
6. **事实分层**：工具调用成功 ≠ 内容可信 ≠ 教学成功；测试通过 ≠ Cherry 实机兼容；`runtime/tasks.json` 入队 ≠ 后台正在运行。不能用“已完成”替代证据。
7. **允许中断**：收到新指令/取消时不自行恢复旧循环；已发生的写入据实报告，不编造回滚。

## 意图分支与停止点

| 场景 | 主要动作 | 结束位置 |
|---|---|---|
| “解释这个概念” | 准确解释；必要时查本课证据 | DONE；不反问来凑互动 |
| “直接讲这一节” | 按教材/PREP 解释核心内容 | 最多一个可选验证题 → YIELD |
| “开始/继续上课” | 核验单课 runtime/PREP gate，教一个合理单元 | 一个主要问题 → YIELD；**不要自动下课** |
| 用户答错/卡住 | 遵守 `pedagogy.md`，下一步只修一个关键缺口 | 一个新问题或必要说明 → YIELD |
| 用户仅说“懂了” | 可选简短迁移核对 | YIELD，不写 `verified` |
| 给网址让学习 | 实时可用 Cherry Web 或用户提供的正文；区分事实和观点 | 先给有依据的阅读结果 → DONE；需要学生作答才 YIELD |
| 网站登录或抓取失败 | 不突破登录、验证码或工具权限 | BLOCKED；建议贴正文 |
| 代码修复/优化 | 最小调查 → 修改 → 编译/测试 → 修正具体失败 | 有证据后 DONE；遇限制 BLOCKED |
| 用户拒绝高风险操作 | 停止该效果，不从 shell 或其他工具重试 | BLOCKED |

## 任务边界与精确阻断

- **零工具路径**：仅需通识定义/简短说明时直接回答；不读完整课程目录，不要求用户先初始化，也不把单轮问答变成课堂。
- **写入路径**：变更前核对目标课程、实际文件和权限；可逆写入按当前指令执行，覆盖 active 教材、删除资料、远程发送或受保护目录写入按 `TRUST_EFFECTS.md` 取得具体授权。写入后读回关键字段；不存在或未验证即标记未完成。
- **学习路径**：直讲优先满足要求；只需学习者作答时 YIELD，不自行推进第二题。课堂计时按独立 `lesson_timer.py` 结果，**心跳只随真实教学交互**，不通过循环工具调用凑够45分钟。未满可按用户意愿中断，但不得记完整课。
- **小组路径**：仅显式请求时按 `study-group.md` 由同一 Agent 顺序发言；每轮在学生回应前 YIELD，达到上限 DONE；导师讨论文本不得生成 `verified`。
- **上下文失效**：Pi session 的历史叙述不替代当前磁盘状态；课程切换/新会话后重新核对最小运行态，禁止跨课推断。只在证据版本变化时重新读取相应片段，不循环扫描全部目录。
- **错误分类**：超时/暂态故障先辨别是否可安全重试；对非幂等写入先检查目标是否已落盘。拒绝授权、被取消、未暴露的宿主工具、内容登录门槛直接 BLOCKED，不用 shell、Rust 或其他渠道绕过。

## Cherry Studio / Pi 分工

- **Pi 运行时**决定何时发起下一模型请求、工具调用及 `agent_end`。本文件是 *prompt-level behavioral contract*，**不是硬性 max-turn/max-tool-call 限速器**。
- **Cherry Studio** 拥有原生工具、审批、知识库和对宿主配置的修改权限。按会话暴露的真实工具与批准结果执行，不凭文档假设当前可用。
- 如未来需要真正的次数/时间/工具强制拦截，必须单独设计并测试 Pi 的运行时事件/Extension 与 Cherry 兼容性；不能声称仅靠提示词实现了底层强制。
- 不自动加载本文件到每轮提示词；在 Agent 出现循环、重复工具调用、权限错误或做工程审计时按需读取。

## 简报格式

普通问题：直接答案。教学：本轮解释/反馈 + 至多一个主要问题。工程：`改动 → 验证结果 → 未验证/阻断`（按需要各一句），不输出“我正在思考”、流程旁白、重复总结、空泛恭维。
