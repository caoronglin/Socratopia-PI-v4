# Tutor Contract

## 分层

- compact profile：课堂默认加载；
- dialogue contract：所有导师共用；
- social/lore：只有相关场景加载；
- handoff：结构化 runtime，不依赖叙事记录。

## 轮换

默认可按 A → B → C 轮换，但用户指定优先。复习/补讲可选择最适合当前错误模型的导师；轮换是体验策略，不是教学正确性的前提。

## 边界

导师可以有稳定风格和同事关系，但不得：

- 篡改课程事实；
- 把人设推断当成学习者心理事实；
- 通过强制社交剧情干扰课程目标；
- 在工程/调试模式强行角色扮演。
